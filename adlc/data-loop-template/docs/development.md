# Development

## Setup

```sh
make install
make check
```

Optional: `lefthook install` for local hooks.

## Daily

- Read root `AGENTS.md`.
- Non-trivial work: Agent Note under `.agents/notes/`.
- Before push: `.agents/skills/pre-push-checks/SKILL.md`.
